# adHRV (adHRV2html) — Анализатор вариабельности сердечного ритма (ВСР)

Набор скриптов для расширенного анализа ВСР с упором на **нелинейные
(энтропийные) показатели**: Sample Entropy (KDTree), Approximate Entropy,
Fuzzy Entropy, Multiscale Entropy и детренд-флуктуационный анализ (DFA α1/α2).

Версия общего блока анализа: `modules/hrvanalysis.__version__`.

## Структура

```
adHRV2html/
├── modules/
│   ├── __init__.py
│   ├── hrvanalysis.py          # общий блок анализа (расчёт метрик, графики, отчёты), __version__
│   ├── html_report_builder.py  # генератор HTML-отчётов (кликабельные графики)
│   └── hrv_norms.json          # конфиг нормативов («светофор»)
├── analys_individual.py        # ОДИН файл/каталог → HTML-отчёт
├── analys_group.py             # ВСЕ .txt в каталоге → ОБЩИЙ XLSX-отчёт
├── analys_with_neurokit2.py    # универсальный анализатор (врем./нелин. через neurokit2, спектр — общий движок)
└── main.py                     # универсальный анализатор (самодостаточная копия ядра)
```

Импорт идёт из пакета `modules`, поэтому скрипты запускаются из корня
`adHRV2html/` (он добавляется в `sys.path` автоматически при запуске и в тестах).

## Зависимости

```bash
pip install numpy scipy pandas matplotlib openpyxl antropy neurokit2
```

- `antropy` используется как запасной (эталонный) вариант для Sample/Fuzzy/
  Multiscale Entropy; основной расчёт Sample Entropy — собственный на базе
  `scipy.spatial.cKDTree`.
- `neurokit2` используется только в `analys_with_neurokit2.py` (временные и
  нелинейные метрики); спектральные мощности во всех трёх скриптах считаются
  **одним и тем же** движком (см. ниже).

## Единый спектральный движок

`analys_individual.py`, `analys_group.py` и `analys_with_neurokit2.py`
генерируют **идентичные** спектральные величины (VLF/LF/HF/TP, LF/HF,
нормированные единицы LF nu / HF nu), поскольку все они используют
`modules.hrvanalysis.compute_frequency_domain_features` (метод Уэлча,
ресемплинг на равномерную сетку 4 Гц, **линейная** интерполяция,
интегрирование методом трапеций). Ранее `analys_with_neurokit2.py`
считал спектр через `neurokit2.hrv_frequency` (значения в с², не совпадали
с PSD-графиком) — это исправлено.

## Использование

**Индивидуальный отчёт (только HTML):**
```bash
python analys_individual.py --file data.txt
python analys_individual.py --dir ./data --all
```
XLSX этим скриптом не формируется (только HTML с интерактивными графиками).

**Групповой отчёт (общий XLSX, без HTML):**
```bash
python analys_group.py --dir . --output hrv_group_report.xlsx
```
Обходит рекурсивно все `*.txt` в выбранном каталоге (по умолчанию — текущем),
использует тот же блок анализа, что и индивидуальный скрипт, и записывает одну
сводную таблицу. Колонки: базовые метрики блока анализа (временные,
спектральные, энтропийные, нелинейные, Poincaré, индексы Баевского) **плюс**
`sd2_sd1_ratio`, `peak_vlf_hz`, `peak_lf_hz`, `peak_hf_hz`, `fraction_lf_nu`,
`fraction_hf_nu`.

**Универсальный отчёт (HTML + XLSX, метрики через neurokit2):**
```bash
python analys_with_neurokit2.py --file data.txt
python analys_with_neurokit2.py --dir ./data --all
```
Спектральные мощности — через общий движок (как выше); временные/нелинейные
(SDNN, RMSSD, SD1/SD2, SampEn, DFA α1) — через `neurokit2`.

## Методологические рекомендации по применению энтропийных метрик

Энтропийные показатели характеризуют **сложность/нерегулярность** сигнала RR.
Их интерпретация и воспроизводимость сильно зависят от подготовки данных и
выбора параметров — ниже сводка правил, которым следует код в `modules/hrvanalysis.py`.

### 1. Подготовка и предварительная обработка
- **Удаление артефактов** обязательно: выбросы (>3σ скользящего среднего,
  окно 5) искажают и спектр, и энтропию. После фильтрации должно остаться
  ≥ 50 RR-интервалов (скрипт даёт ошибку иначе; для энтропии нужно больше — см. п. 2).
- **Ресемплинг** спектра выполняется на равномерную сетку 4 Гц (**линейная**
  интерполяция `np.interp`). Энтропийные метрики считаются **по исходному ряду RR**
  (не по ресемплированному), чтобы не вносить искусственную корреляцию.
- Сигнал предварительно **центрируется** (вычитается среднее) перед Welch-спектром.

### 2. Требования к длине записи
| Метрика | Минимум RR | Комментарий |
|---------|-----------|-------------|
| Sample / Approximate / Fuzzy Entropy | ~200–250 | при m=2; короче — нестабильно |
| Multiscale Entropy | ≥ 500–1000 | нужны масштабы до 20 |
| DFA α1 / α2 | ≥ 100–150 | α1 — короткие шкалы (4–16), α2 — длинные (17–64) |
| Спектр VLF | длительность ≥ 5 мин | иначе разрешение по частоте (df≈4/256≈0.016 Гц) грубо недооценивает VLF |

Если запись слишком короткая, метрика возвращает `NaN`/0.0 и исключается из таблицы
(колонка «Статус» отсутствует; цвет «светофорa» перенесён на ячейку
«Интерпретация»).

### 3. Параметры энтропии (m, r)
- **m = 2** (размерность вложения) — стандарт для ВСР.
- **r** (допуск сравнения):
  - Sample Entropy / Approximate Entropy: `r = 0.2` × SD сигнала (классика Richman–Moorman).
  - Fuzzy Entropy: `r = 0.15`, экспонента `n = 2`.
- Энтропии **чувствительны к r**: сравнивайте группы только при **одинаковых m и r**,
  иначе различия могут быть артефактом параметра, а не физиологии.

### 4. Интерпретация
- **Высокая энтропия** (SampEn, FuzzyEn, MSE) = высокая сложность/адаптивность
  регуляции, в норме выше у здоровых. **Снижение** — при патологии, стрессе,
  возрасте, диабете, СН.
- **MSE mean / slope**: среднее по шкалам и наклон. Пологий/снижающийся slope —
  потеря сложности на больших масштабах.
- **DFA α1** ≈ 1.0 (шумовой антиперсистентный процесс), **α2** > α1 обычно;
  отклонения α1 от ~1 указывают на изменение коррелированности.
- Энтропии **относительны**: абсолютные значения зависят от реализации, поэтому
  в первую очередь используются **сравнения внутри выборки/когорты**, а не
  абсолютные пороги.

### 5. Спектральные доли (nu) против отношения LF/HF
- `Fraction LF (nu)` / `Fraction HF (nu)` — **нормированные единицы**:
  `LF/(LF+HF)·100`, `HF/(LF+HF)·100`. Они отражают **баланс** симпато-вагусной
  регуляции, очищенный от общего уровня мощности.
- `LF/HF ratio` — простое отношение абсолютных мощностей. Чувствительно к
  общей мощности и к VLF-составляющей.
- Используйте **nu** для межгрупповых сравнений баланса, **ratio** — для
  общего суждения о вагосимпатическом тонусе.
- `Peak VLF/LF/HF (Hz)` — частоты пиков PSD в соответствующих полосах;
  полезны для оценки сдвига центральных частот (например, дыхательной модуляции).

### 6. Воспроизводимость
- Для сопоставимости держите **единый пайплайн**: один метод фильтрации,
  один fs ресемплинга (4 Гц), одни m/r, одинаковую минимальную длительность.
- Не смешивайте разные реализации энтропии (здесь — собственная KDTree +
  опционально `antropy` как фолбэк); при публикациях указывайте библиотеку/версию.
- VLF-мощность при коротких записях систематически **занижается** из-за
  разрешения по частоте — интерпретируйте её осторожно и только для длинных
  (≥5 мин) записей.

### 7. Конфигурация нормативов
- Нормативы («светофор») хранaтся в `modules/hrv_norms.json`. При отсутствии
  файла используются встроенные значения. Ключ `--config` позволяет подставить
  свой набор (для пересчёта интерпретаций/цветов).

### 8. Производительность нелинейного анализа
Замеры на `АСЛАНОВ_БАЗА_ТЕСТЫ_epoch_01_Whole_File.txt` (n≈3040 RR после
фильтрации; см. `WHATS.new`):

| Скрипт | Нелинейный блок | Время |
|---|---|---|
| `analys_individual.py` | `compute_entropy_features` (SampEn, DFA α1/α2, ApEn, FuzzyEn, MSE) | **≈ 3.5 с** |
| `analys_with_neurokit2.py` | `nk.hrv_nonlinear` (SD1, SD2, SampEn, DFA α1) | **≈ 18.6 с** |

`analys_with_neurokit2.py` в ~5 раз медленнее, хотя считает *меньше* нелинейных
метрик (без ApEn/FuzzyEn/MSE) — узкое место во внутренней реализации SampEn/DFA
в `neurokit2`. При необходимости максимальной скорости используйте
`analys_individual.py` / `analys_group.py`.
